# Contributing

Thanks for interest in OpenTrainer.

## How to contribute

1. **Fork** the repo and create a branch from `main`.
2. Make your change (keep PRs focused).
3. Open a **pull request** against `main`.
4. Wait for review — merges require approval from the code owner (`@janpetr93`).

Direct pushes to `main` are not available to contributors.

## Local setup

See the [README](README.md) Quick start. Use Chrome or Edge for the Ride UI.

Do not commit secrets: copy `companion/.env.example` → `companion/.env` and keep real credentials local.

## Issues

Bug reports and feature ideas via [GitHub Issues](https://github.com/janpetr93/OpenTrainer/issues) are welcome. For security issues, see [SECURITY.md](SECURITY.md).
