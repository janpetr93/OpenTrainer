# Meter-primary Power Source Mode with hybrid ERG

When a **Power Meter** is connected and fresh at **Start**, OpenTrainer treats meter watts as primary for **Live Power**, achieved **Power Profile** / FIT / Session Load / MMP, and **Target Prescription** resolution. The **Trainer** remains the ERG actuator: FTMS setpoints come from **ERG Calibration** (durable scale/offset in a Local Store file) plus light closed-loop trim from meter error while both streams are fresh. Without a meter, behavior stays **trainer-primary**. Mid-ride meter loss does not flip primary for that session. This matches outdoor Assioma training numbers without forcing a meter on trainer-only riders, at the cost of ERG setpoints that can differ from on-screen target watts and a dual-stream Activity shape (`watts` + `trainerWatts` in meter-primary).
