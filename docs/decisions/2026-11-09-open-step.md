# Open Step inside a Workout

## Context

A self-paced block such as a 20-minute FTP test needs ERG for the warmup and then a stretch where the rider chooses power. A **Workout** step with every target empty is already allowed in the store, and the runner reports no watts for it. The ERG push then sends nothing, so the **Trainer** keeps the previous setpoint. **Free Ride** is a whole **Activity** with no **Workout**, and once a **Free Ride Target** is set it is also ERG. FTMS has no command to drop ERG short of reset or indoor-bike simulation.

## Decision

An **Open Step** is a **Workout** step with a duration and no **Target Prescription** (its own step type, not an empty warmup/steady/recovery/cooldown).

While it runs, the **Trainer** leaves ERG for indoor-bike simulation at 0% grade. The next step that has a **Target Prescription** returns to ERG. If the trainer rejects simulation, the ride pauses on that step and stays in ERG; Start of the **Workout** is not blocked. Resume retries simulation.

The planned **Power Profile** stores no watts for the open seconds, not a 0 W segment. The chart draws a wave across that span (a display-only sine, not a target). **Session Adherence** scores targets only on prescribed seconds. Completion still includes the open time. **Session Load** uses achieved power for the whole **Activity**.

**Ride Intensity** and its keys do nothing while the **Open Step** is current, so a nudge cannot send ERG. An intensity set on an earlier step still applies when the next prescribed step resumes ERG.

An **Open Step** does not change session kind. `sessionKind` and `check_training_week` stay based on prescribed steady targets. The planning model sees the step and **Session Purpose** and treats an FTP test as a hard session without a duration rule in the checker.

## Alternatives considered

- **Leave the last ERG setpoint** — the rider stays locked at the warmup watts.
- **Call the block a Free Ride** — **Free Ride** is an **Activity** with no plan, and its target nudge is ERG.
- **Count an Open Step of at least 8 minutes as hard** — rejected. The planner already has the workout and the purpose, so a cutoff in the week check is not what keeps a test from being stacked with other hard days.

## Consequences

- MCP `create_workout` must accept the step. Week planning does not gain an automatic FTP-test protocol, and nothing writes **FTP** from the result.
- The ride chart draws a wave across the open span. Strava step text and adherence must not treat it as 0 W.
